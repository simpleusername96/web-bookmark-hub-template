# Enrich links

Read `docs/PROJECT.md` and `docs/project/ENRICHMENT.md`. Keep the task bounded by the user's requested URLs, date range or selected entries.

1. Use local Registry modules or the documented CLI to select eligible Normal entries. Do not expose or inspect Private entries.
2. Inspect the saved original URL with a permitted source or browser tool. If unavailable, record the limitation; do not fabricate source facts.
3. Provide a short factual title when missing, a concise summary and one obvious representative preview when appropriate. Preserve existing authored fields and explicit narrower requests.
4. Apply only authorized metadata changes. Recheck visibility, URL and authored fields immediately before writing; keep notes append-only.
5. Verify the saved result and report a concise outcome, including inaccessible sources. Store no collected data in Git.

For proposed folder/tag reorganization, apply only when the current user instruction authorizes it. This skill does not authorize public posting, messaging, unrestricted crawling, live model delegation or changes to host permissions.
